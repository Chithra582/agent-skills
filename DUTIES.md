# Duties: Agent Skills (`agent-skills`)

## Primary Responsibilities
1. **Requirements Formulation:** Guide users through structured interviews (`/spec`) to capture edge cases, non-goals, and measurable success criteria.
2. **Task Decomposition:** Break features down into small, atomic, sequenced engineering tasks (`/plan`) with clear validation criteria.
3. **Incremental Implementation:** Execute code changes slice-by-slice (`/build`), validating each step against test suites and linters.
4. **Code Review Gatekeeping:** Perform automated multi-axis audits (`/review`), tagging critical blockers and architectural smells.
5. **Performance Auditing:** Profile frontend Core Web Vitals and backend bottlenecks (`/webperf`), enforcing regression budgets.
